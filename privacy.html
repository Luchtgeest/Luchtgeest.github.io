Privacy Policy / 개인정보처리방침

Last updated: 2026-11-09

What this app does / 앱이 하는 일

akasha-nas-rclone is a personal tool used only by its owner. It uploads the owner's own files from a home NAS to the owner's own Google Drive.

akasha-nas-rclone은 소유자 한 사람만 쓰는 개인 도구입니다. 소유자의 집 NAS에 있는 소유자 본인의 파일을 소유자 본인의 구글 드라이브에 올립니다.

Data accessed / 접근하는 데이터

The app accesses only the Google Drive of the account that signs in (the owner). It reads folder lists and uploads files to that Drive.

로그인한 계정(소유자)의 구글 드라이브에만 접근하며, 폴더 목록을 읽고 그 드라이브에 파일을 올립니다.

Data sharing / 데이터 공유

No data is collected, sold, or shared with anyone. Nothing is sent to any server other than Google Drive. The sign-in token is stored only on the owner's NAS.

어떤 데이터도 수집·판매·제3자 제공하지 않습니다. 구글 드라이브 외의 서버로 보내지 않으며, 로그인 토큰은 소유자의 NAS에만 저장됩니다.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access / 접근 해제

The owner can remove access at any time at myaccount.google.com/connections.
